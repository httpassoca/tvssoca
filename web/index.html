tvssoca

The CleanYourTV launcher interface rebuilt on dssoca 0.19. Behaviour, geometry and focus physics are the launcher's; every surface, colour and type choice is a dssoca token or component. Click the screen and drive it with a remote.

The CSS comes from dssoca's own theme.css and vanilla.css (0.19.0). The page uses dssoca's Button, Menu, Badge, Card, Segmented control, Switch, Heading, Kbd and Toaster as they come. The code is split into config, catalog, store, layout, views, focus and motion. The config keys match the launcher's config.xml, and the input layer speaks Android key names (DPAD_UP, BACK…), so a TV build can reuse the logic and swap only the view layer. App tiles are invented stand-ins.
